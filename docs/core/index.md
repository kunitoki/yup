# Core

Foundational utilities used across every YUP module.

**Modules covered:** `yup_core`, `yup_simd`.

## Topics

- **Strings & text** - `String`, text encodings, and formatting.
- **Files & streams** - file access, streams, and I/O.
- **Memory** - smart pointers, reference counting, and RAII helpers.
- **Containers** - arrays and associative containers.
- **Results** - `Result` and `ResultValue<T>` for fallible operations.
- **SIMD** - vectorized math primitives (`yup_simd`).
