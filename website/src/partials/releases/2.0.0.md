## [2.0.0] - Unreleased

YUP goes 3D, gets its own JIT-compiled DSP language and a portable GPU layer, and its interface becomes touch-first with a much larger widget set.

### 3D

- A new 3D module: scenes built as a small entity-component system, scenes with prefabs and glTF 2.0 model loading.
- A new renderer with two tiers: a forward raster tier that runs everywhere, and a full tier with HDR, temporal anti-aliasing and deferred shading with any number of lights.
- Cascaded sun shadows, soft point and spot shadows, contact shadows, ambient occlusion, screen-space reflections, reflection probes and irradiance volumes.
- Depth of field with a physical camera, motion blur, height fog, bloom, ACES and AgX tone mapping, and temporal upscaling.
- Picking with rays, per-frame GPU statistics and debug views for depth, normals, motion and materials.

### GPU

- A new RHI module: render and compute pipelines, buffers, textures, samplers and depth targets on Metal, Direct3D 11, OpenGL, WebGPU and Vulkan.
- Vulkan is a new backend, and the default on Android. On macOS, rendering is Metal only.
- Compute shaders on Metal, Direct3D 11, OpenGL, Vulkan and WebGPU, with a GPU audio processing demo.
- Write shaders once in GLSL: they compile to MSL, HLSL, GLSL ES, SPIR-V and WGSL, and ship as compressed shader bundles built with your project.
- WebGPU is the default renderer in the browser, falling back to compatibility mode on older GPUs.

### YDSP

- YDSP is a new real-time DSP language compiled at runtime to native ARM64 and x86-64 code, and to WebAssembly SIMD in the browser.
- Processors and graphs combine Faust-style composition with Cmajor-style definitions: voice banks, MIDI and MPE events, oversampling and undersampling, automatic delay compensation and parameter smoothing.
- An optimizing compiler with vectorization, fused math and bounds checks that cost nothing when they can be proven safe.
- Projects and precompiled bundles, a command line compiler and player with hot reload, and a VS Code extension.
- The graphics example plays a collection of YDSP synths, from electric piano to drums.

### Graphics

- Color emoji in every text, Unicode line breaking, and a monospace font in the default theme.
- Image meshes for warping and instanced sprites, clipping to strokes, layer masks, additive blending and inside or outside strokes.
- TIFF, TGA, animated PNG and animated WebP images, with metadata.
- Rive updated, with grid layout, scripted files, ViewModel data binding and full input on artboards.
- Lottie gains merge paths and better mattes, precompositions and expressions.

### Interface

- Multitouch everywhere, and gestures: tap, double tap, long press, pinch, rotate, pan and swipe.
- New widgets: tabs, tree views, a touch-first list box with fling scrolling, and a code editor with syntax highlighting.
- Themes from a palette: give it any colors and the whole app recolors at runtime, in dark or light mode.
- Drag and drop that carries any data and can leave the app.
- FlexBox and Grid layouts that follow the CSS rules, with named areas, gaps, padding and auto margins.
- Transforms apply to whole component trees.
- Windows can be transparent, always on top or unfocusable (desktop).
- Every window renders on its own thread, paced to its display's refresh rate.

### Audio

- New oscillators and filters: a spectral Prism oscillator, band-limited modulated oscillators with FM and phase distortion, a virtual analog state variable filter and an LFO.
- Halfband and faster sinc oversamplers, double precision FFTs and tuning maps for any scale.
- Web MIDI in the browser, pitch and mod wheels, and a multitouch MIDI keyboard.

### AI

- A new AI module: chat clients for OpenAI, Anthropic, Gemini and compatible servers, with streaming, tool calling and structured output.
- Embeddings, and Model Context Protocol clients and servers.

### Core and tools

- YAML, signals with scoped connections, cancellation tokens and timers precise to below a millisecond.
- Security hardening across strings, XML, JSON, YAML, archives, zip files, networking and file permissions, plus a cryptographic random generator.
- Much wider Python bindings, including the GPU layer, layouts and AI.
- Bundled resources and app icons in the build, Android 16 KB page support, and building the tests of selected modules only.

This is a major release with breaking changes. The [changelog](https://github.com/kunitoki/yup/blob/main/CHANGELOG.md) lists each one and how to migrate.
