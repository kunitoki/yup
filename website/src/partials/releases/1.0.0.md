## [1.0.0] - 2026-07-03

The first release of YUP: one C++ codebase for apps and audio plugins, painted on the GPU, running on desktop, mobile and the web.

### Everywhere

- Windows, macOS, Linux, iOS, Android and the browser, built from the same sources.
- In the browser, audio runs in an AudioWorklet and apps can use threads, with a file system to read and write.
- Mobile apps keep their content clear of notches and system bars, and every desktop scales with high density displays.

### Graphics

- A GPU renderer on Metal, Direct3D and OpenGL, built on Rive: paths, gradients, strokes with soft edges and text.
- SVG 1.1 drawing, and reading and writing PNG, JPEG, WebP, animated GIF, BMP and Netpbm images.
- Offscreen rendering to images and textures, with group opacity layers.

### Animation

- A new animation module plays Lottie files: playback in both directions, loops, speed and seeking, with expressions.
- Animations can be edited in code, saved back to Lottie, and exported as frames or as animated GIFs.

### Audio

- Build plugins as CLAP, VST3 and Audio Unit (AUv2), plus early AUv3, AAX and LV2, with sidechains and multiple buses. Plugins also run as standalone apps.
- Host CLAP, VST3 and Audio Unit plugins inside your own app, and connect them in an audio graph.
- Read and write WAV, FLAC, Opus, MP3 and AAC, with the native decoders on Apple platforms and Windows.
- A DSP module: FFT, IIR and FIR filters, crossovers, virtual analog filters, convolution, oversampling, time stretching, spectral processing, onset detection and distortion.
- MIDI 2.0 support through Universal MIDI Packets.

### Interface

- Themes for every widget, popup menus, combo boxes, text editors and labels, a native file chooser, drag and drop and the clipboard.
- Audio widgets: a MIDI keyboard, filter response curves, a spectrum analyzer, a spectrogram and an oscilloscope.
- Rive artboards inside the interface, driven by their state machines.
- A paint profiler to see where each frame's time goes.

### Data and tools

- A data model for app state: an observable tree with transactions, undo, queries and schema validation.
- SQLite databases, file watching, a JavaScript engine, SIMD math and Perfetto profiling.
- Python bindings for YUP.

### Build

- CMake modules that pull in what they depend on, catch circular dependencies and set per platform options.
- Plugin validation and code signing in the build, code coverage, and sharded test runs.

Plus many fixes across platforms, from a startup crash on custom scaled screens to thread safety in CoreAudio and the audio device manager.
